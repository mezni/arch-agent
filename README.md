# My AI Library (`my_ai_lib`)

A lightweight, high-performance Python library designed for AI workflow utilities, featuring a fast prompt optimizer and built with modern tooling (`uv`, `pytest`, and `ruff`).

---

## Features

- **Prompt Rewriter (`prompt_rewriter`)**: Automatically clean up, format, and enhance text prompts for AI consumption with multiple styles (`concise`, `detailed`, `markdown`).
- **Dynamic Versioning**: Easily track package versions using standard library metadata.
- **Lightning-Fast Tooling**: Built and managed with Astral's `uv`.

---
